# Implementation journal: Name

Append entries as work happens. Do not reconstruct unmeasured time or claim an unrun test passed.

## Entry template

- Date and time: Actual local date/time, or date only
- Work performed: Files, public API changes, native behavior
- Reason and alternatives: Link to proposal or ADR; note new choices
- Validation: Exact commands, devices, build variant, and result
- Failures or surprises: Observed error and resolution or open status
- Development time: Measured duration and method, or **not measured**
- Evidence: Links to code, logs, issue, or experiment
- Next step: Concrete follow-up
