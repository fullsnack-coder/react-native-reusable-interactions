# AnimatedBalance implementation journal

## 2026-11-08 / 2026-11-09 — design and implementation

Development time not measured. Inspected all four repository instructions, prior components, installed React Native/UI-UX skills, package mechanism, tests and Release evidence. Current AGENTS.md separates implementation readiness from release readiness; prior native/accessibility gaps are carried forward. No dependency/version changes or generic animation framework.

Chose bounded decimal strings and controlled snapshots. Intl supplies locale literals and grouping; fractional digits never enter a Number. Initial implementation used formatToParts, with passing Node formatter tests. Native iOS Debug showed that Hermes lacks this method (captured error). Replaced it with a validated Intl.format glyph tokenizer: exact integer output and zero fraction are checked before substituting the exact localized fraction. Negative subunits use a -1 pattern and substitute zero rather than depending on signed-zero support. Added a regression with formatToParts removed. ADR 0006 records the final decision.

Columns have decimal-relative identity, fixed measured maximum digit width, one cyclic offset and a fixed 30-row Text strip. Retargeting normalizes UI progress without a visual phase change; no completion callbacks/queues or per-frame React/formatting. System motion preference defaults conservatively to snapping, then listens for updates. Unicode/bidi formats use whole native Text. One accessibility label exposes only the latest complete formatted value; app controls announcements.

Native inspection found a second defect: currency/separators were visible but rolling digits were clipped away because the strip lacked an explicit full height. Added an explicit 30-cell height to both strip and Text, plus a regression assertion. Native retest results are recorded below; do not infer visual success from mocked tests.

Initial test infrastructure failures included non-configurable ESM spies, missing ESM flag in the wrapper mock, deferred Worklets queues requiring timer advancement, duplicate composite/host test nodes, OS fontScale=2 in the RN preset, and unrelated global timer counts. Corrected test setup/expectations; previous component test assertions remain preserved. Showcase App's mount test now uses async act for the new asynchronous motion-preference initialization. Strict RN ScrollView ref types require ComponentRef rather than the old class type.

Showcase uses only the packed public API. It adds fictional presets, atomic currency/value changes, four-value 100-ms rapid updates with owned timer cleanup, narrow/overflow, hide/remount and reset controls. A small native catalog jump button makes the fourth demo reachable without introducing a navigation dependency or redesigning existing demonstrations. Public reference and landing text have been added; final native outcomes, metrics and checks are recorded as actually executed.
