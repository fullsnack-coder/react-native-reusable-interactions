# Publishing runbook

The candidate ships the reviewed [publishing runbook](../../../../docs/release/publishing.md). It contains prerequisites, account/scope/name recheck, MIT/Issues decisions, clean commands, actual pack/consumer validation, exact-artifact owner approval, the future explicit beta-tag publication command, post-publication install verification and deprecation/rollback limits. **No publication command was executed in this iteration.**

Owner license/channel confirmations do not authorize publication. Critical reader gates remain pending; no automatic remote/tag/release/deploy/store workflow exists.
