# Six-component public API audit

2026-11-10. Source/declarations/public docs/meaningful tests inspected. No mechanical API standardization or new interaction. Current native/reader/device scope is in separate evidence.

| Component                       | Findings / action                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| ExpandableTransactionCard       | Controlled expanded or internal defaultExpanded; requested toggle ref supports rapid requests. Measured absolute detail body drives reveal height; hidden details block touch/AX. Spring values lacked validation and motion lacked explicit unmount cancellation: add finite/positive guards and cleanup; valid API unchanged. Navigation independent.                                                                                                                                          |
| CardStackSelector               | Generic items, unique stable IDs, measured caller cardHeight, controlled/uncontrolled selection/expansion; deterministic first-item fallback after removal, no synthetic selection callback. Empty returns null, single safe, layer order depends on identity. Retain behavior/document fallback. Add finite/positive spring validation consistent with Swipe; large collections/virtualization not promised.                                                                                    |
| SwipeToPay                      | Required controlled status, one-intent latch, explicit idle/resetKey rearm, threshold0.5..1 and spring/height guards, RTL pan, queued-generation rejection. Native cancellation and accessible activation differ. Physical owner reported vertically low font arrow; native screenshot confirmed. Replace only decorative glyph with centered native geometry, keep RTL and semantic/intent contracts; regression checks maintain decorative/RTL activation. No operation/payment authorization. |
| AnimatedBalance                 | Required bounded decimal string,15 integer/6 fraction digits, no floating-point amount conversion; locale/currency/fraction validation, exact carry/rounding and native Intl scope. Animated digit stripping and stale/cleanup guards remain. One complete accessible value; actual spoken output still requires reader testing. No arithmetic/business operation.                                                                                                                               |
| HoldToConfirm                   | Required consumer status, native gesture-authoritative duration500..10000 ms, latch/generation/cancel/multitouch, AppState/Android focus cleanup and accessibility activate alternative. Explicit rearm; no JS timer authorizes confirmation. Retain existing valid API.                                                                                                                                                                                                                         |
| InteractivePurchaseSheet / Host | Required controlled visibility/index and measured insets;1..4 increasing fractions0.2..1, separate requests/settled/completed callbacks. One owner per root host; explicit missing/multiple host errors. Body scroll never pans sheet; no nested vertical virtualization/arbitrary native Modal layering. Main-root keyboard avoidance/restore and best-effort AX focus requests; no full focus/speech claim. Context providers must wrap host.                                                  |

Optional configuration differs by interaction for legitimate reasons; no new generic framework. All public prop/status/host/reason/spring types are root-exported and compiled by the independent consumer. ESM Metro output is intentional; no generic Node/CommonJS/Web support promised. Consumers own themes, localization, custom content and results. Invalid nonpositive/nonfinite disclosure/stack springs now fail before native motion; this intentional validation change is noted before first publication. The spring tests cover0/-1/NaN/Infinity; native smoothness is not inferred from them.
