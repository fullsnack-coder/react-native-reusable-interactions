# Generated development shell

This small native shell is separate from the six-demo standalone showcase and the disposable independent release consumer. It currently displays a placeholder, so a successful launch is not validation of any component interaction.

Prepare the library artifact in ../artifacts (the scoped 0.1.0-beta.1 filename), explicitly refresh the example package-lock after replacing same-version bytes, then npm ci. Babel already uses the Worklets plugin; GestureHandlerRootView is provided. npm run typecheck uses this example's own tsconfig and TypeScript dev dependency rather than accidentally walking to the parent library configuration. Native builds require the usual JDK/SDK or Xcode/pods. No source symlink into the parent library is used by the package dependency.
